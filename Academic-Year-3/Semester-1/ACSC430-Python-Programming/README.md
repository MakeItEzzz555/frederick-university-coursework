## Tools and run notes

Use Python 3 and the standard library. Run each `.py` independently and follow its prompts. Turtle requires a working Tk GUI. The product menu needs the companion Product.py module; run from its folder, choose CSV loading and enter `All_Products.csv`. Use a new filename when saving to preserve the sample catalog. Basic cone geometry uses 3.14; the validated variant uses math.pi.

Earlier compilation/syntax or limited smoke checks are recorded in the archival reports. This migration verifies byte preservation, organization, privacy and repository completeness; it makes no new claim that all interactive behavior was tested.
