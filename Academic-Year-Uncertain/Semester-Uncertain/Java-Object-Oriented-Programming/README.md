## Tools and run notes

Use JDK 17 or a compatible JDK. Compile each unrelated exercise separately into a disposable output directory with `javac -encoding UTF-8 -d out *.java`, then run its entry class with `java -cp out ClassName`. Lab-07-Account source is under `src`. For Lab-10-Police, compile files in all five subdirectories together and run TestPolice. Lab-04 task1.java is a helper.

Earlier compilation/syntax or limited smoke checks are recorded in the archival reports. This migration verifies byte preservation, organization, privacy and repository completeness; it makes no new claim that all interactive behavior was tested.
